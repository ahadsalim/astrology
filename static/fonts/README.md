# راهنمای دانلود فونت‌ها

برای استفاده آفلاین از فونت‌ها، فایل‌های زیر را دانلود کنید:

## فونت Vazirmatn

### دانلود مستقیم:
1. [Vazirmatn-Regular.woff2](https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Regular.woff2)
2. [Vazirmatn-Medium.woff2](https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Medium.woff2)
3. [Vazirmatn-Bold.woff2](https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Bold.woff2)

### دانلود از GitHub:
https://github.com/rastikerdar/vazirmatn/releases/latest

### نحوه استفاده:
1. فایل‌های woff2 را دانلود کنید
2. در این پوشه (`static/fonts/`) قرار دهید
3. نام فایل‌ها باید دقیقاً مطابق موارد زیر باشد:
   - Vazirmatn-Regular.woff2
   - Vazirmatn-Medium.woff2
   - Vazirmatn-Bold.woff2

## وضعیت فعلی:
✅ CSS برای استفاده از فونت‌های محلی آماده است
✅ در صورت عدم وجود فونت محلی، از CDN استفاده می‌شود (نیاز به اینترنت)
⚠️ برای کار کامل آفلاین، فونت‌ها را دانلود کنید

## تست:
بعد از قرار دادن فونت‌ها:
1. سرور را ریستارت کنید
2. اینترنت را قطع کنید
3. صفحه را رفرش کنید
4. اگر فونت‌ها درست نمایش داده شدند، آفلاین کار می‌کنند ✓
