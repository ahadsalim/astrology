# Vazirmatn

Self-hosted from the official release. Nothing is loaded from a CDN.

- Release: [v33.003](https://github.com/rastikerdar/vazirmatn/releases/tag/v33.003)
- Archive: https://github.com/rastikerdar/vazirmatn/releases/download/v33.003/vazirmatn-v33.003.zip
- Web: `Vazirmatn-Variable.woff2` (original path `fonts/webfonts/Vazirmatn[wght].woff2`)
- Chart rendering: `Vazirmatn-Regular.ttf` and `Vazirmatn-Bold.ttf` (`fonts/ttf/`)
- License: `OFL.txt` (SIL Open Font License 1.1)

`vazirmatn.css` declares the variable face for weights 100–900 with `font-display: swap`.
