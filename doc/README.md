# 🌙 سامانه تحلیل زایچه تولد (Nojoom)

سامانه تحلیل جامع نجومی بر اساس نجوم احکامی ایرانی-اسلامی با استفاده از هوش مصنوعی و محاسبات دقیق Swiss Ephemeris.

## ✨ ویژگی‌ها

- 🔮 **تحلیل جامع نجومی**: تحلیل کامل زایچه تولد بر اساس نجوم احکامی
- 📊 **محاسبات دقیق**: استفاده از Swiss Ephemeris برای محاسبات نجومی دقیق
- 🤖 **هوش مصنوعی پیشرفته**: تحلیل توسط مدل‌های زبانی پیشرفته
- 📱 **طراحی Responsive**: سازگار با موبایل، تبلت و دسکتاپ
- 🎨 **رابط کاربری مدرن**: طراحی زیبا و کاربرپسند
- 🔒 **امنیت بالا**: استفاده از متغیرهای محیطی برای اطلاعات حساس
- ✅ **اعتبارسنجی ورودی**: بررسی دقیق تمام ورودی‌های کاربر
- 📝 **ساده‌سازی متن**: تبدیل تحلیل تخصصی به زبان ساده
- 🖨️ **قابلیت چاپ**: امکان چاپ و ذخیره نتایج

## 📋 پیش‌نیازها

- Python 3.8 یا بالاتر
- pip (مدیر بسته‌های Python)

## 🚀 نصب و راه‌اندازی

### 1. کلون کردن پروژه

```bash
git clone <repository-url>
cd app
```

### 2. ایجاد محیط مجازی (اختیاری اما توصیه می‌شود)

```bash
python -m venv venv

# در Windows:
venv\Scripts\activate

# در Linux/Mac:
source venv/bin/activate
```

### 3. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

**نکته**: اگر در نصب `pyswisseph` مشکل داشتید، از دستور زیر استفاده کنید:

```bash
pip install pyswisseph -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 4. تنظیم متغیرهای محیطی

فایل `.env.example` را کپی کرده و نام آن را به `.env` تغییر دهید:

```bash
copy .env.example .env
```

سپس فایل `.env` را ویرایش کرده و مقادیر زیر را تنظیم کنید:

```env
API_KEY=your_actual_api_key_here
API_URL=https://api.gapgpt.app/v1
ASTRO_MODEL=gpt-5.2
SIMPLIFY_MODEL=gpt-5.6-luna
SECRET_KEY=your_secret_key_here
```

**مهم**: حتماً `API_KEY` را با کلید واقعی API خود جایگزین کنید.

### 5. اجرای برنامه

```bash
python app.py
```

برنامه روی آدرس `http://localhost:5000` اجرا خواهد شد.

## 🔧 استفاده

### 1. ورود اطلاعات تولد

در صفحه اصلی، اطلاعات زیر را وارد کنید:

- **نام**: نام فرد
- **تاریخ تولد**: به فرمت شمسی (مثال: `1360-06-19` یا `19-06-1360`)
- **ساعت تولد**: به فرمت 24 ساعته (مثال: `14:30`)
- **محل تولد**: نام شهر (برای محاسبات دقیق به انگلیسی: `Tehran, Iran`)
- **دغدغه اصلی** (اختیاری): شغل یا موضوع مورد نظر

### 2. انتخاب نوع محاسبات

- **بله - محاسبه دقیق**: استفاده از Swiss Ephemeris برای محاسبات دقیق
- **خیر**: تحلیل بدون محاسبات دقیق (AI خودش محاسبه می‌کند)

### 3. دریافت نتایج

پس از کلیک روی دکمه "تحلیل زایچه"، تحلیل جامع نجومی شامل موارد زیر نمایش داده می‌شود:

1. **ترسیم دقیق زایچه**: موقعیت کواکب، طالع، و خانه‌ها
2. **تحلیل شخصیت**: بررسی روانشناختی بر اساس زایچه
3. **کالبدشکافی 12 خانه**: تحلیل دقیق هر خانه
4. **مثلث مالی و شغلی**: راهنمای شغلی و مالی
5. **نجوم پزشکی**: بررسی سلامت جسمانی
6. **رسالت کارمایی**: تحلیل گره‌های قمری
7. **ترانزیت‌های فعلی**: وضعیت فعلی و پیش‌بینی

### 4. عملیات روی نتایج

- **نسخه ساده**: تبدیل تحلیل به زبان ساده
- **پرینت**: چاپ نتایج
- **کپی متن**: کپی کردن متن به کلیپبورد
- **تحلیل جدید**: بازگشت به صفحه اصلی

## 🐛 رفع مشکلات رایج

### خطای "API_KEY is required"

مطمئن شوید فایل `.env` ایجاد شده و `API_KEY` در آن تنظیم شده است.

### خطای نصب pyswisseph

از دستور زیر استفاده کنید:
```bash
pip install pyswisseph -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### خطای "Swiss Ephemeris not available"

اگر کتابخانه‌های نجومی نصب نشده‌اند، برنامه همچنان کار می‌کند اما بدون محاسبات دقیق.

### خطای "Could not find location"

نام شهر را به انگلیسی و با فرمت صحیح وارد کنید (مثال: `Tehran, Iran`)
