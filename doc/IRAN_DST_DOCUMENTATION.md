# 🕐 مستندات کامل ساعت تابستانی ایران

## تاریخچه رسمی DST در ایران

### 📅 دوره‌های اجرای DST

#### ✅ دوره اول: 1977-2005 (1356-1384 شمسی)
- **شروع**: 1977 (1356 شمسی)
- **پایان**: 2005 (1384 شمسی)
- **مدت**: 29 سال
- **وضعیت**: DST فعال بود

#### ❌ دوره لغو: 2006-2007 (1385-1386 شمسی)
- **تاریخ لغو**: 2006
- **دلیل**: تصمیم دولت محمود احمدی‌نژاد
- **مدت**: 2 سال
- **وضعیت**: DST لغو شد

#### ✅ دوره دوم: 2008-2022 (1387-1401 شمسی)
- **شروع**: 21 مارس 2008 (1 فروردین 1387)
- **پایان**: 21 سپتامبر 2022 (30 شهریور 1401)
- **دلیل بازگشت**: تصویب قانون توسط مجلس در سپتامبر 2007
- **مدت**: 14 سال و 6 ماه
- **وضعیت**: DST مجدداً فعال شد

#### ❌ لغو دائمی: از 21 سپتامبر 2022
- **تاریخ لغو**: 21 سپتامبر 2022 (30 شهریور 1401)
- **دلیل**: تصویب طرح لغو توسط مجلس در 15 مارس 2022
- **تأیید**: شورای نگهبان و ابلاغ توسط رئیس‌جمهور در 22 مه 2022
- **اجرا**: فوری از 21 سپتامبر 2022
- **وضعیت فعلی**: ایران همیشه از UTC+3:30 استفاده می‌کند

#### ⚠️ بازگشت جزئی: می 2025 (فقط تهران)
- **محدوده**: فقط شهر تهران
- **وضعیت**: غیررسمی و محلی
- **استفاده در محاسبات**: خیر (چون سراسری نیست)

## 🔧 قوانین تبدیل DST

### زمان شروع DST (در سال‌های فعال)
- **تاریخ شمسی**: 1 فروردین (اول سال نو)
- **تاریخ میلادی**: 20 یا 21 مارس (بسته به اعتدال بهاری)
- **ساعت**: 00:00 (نیمه‌شب)
- **تغییر**: ساعت‌ها 1 ساعت به جلو می‌روند (00:00 → 01:00)
- **نتیجه**: UTC+3:30 → UTC+4:30

### زمان پایان DST (در سال‌های فعال)
- **تاریخ شمسی**: 30 شهریور (آخر تابستان)
- **تاریخ میلادی**: 20 یا 21 سپتامبر
- **ساعت**: 00:00 (نیمه‌شب)
- **تغییر**: ساعت‌ها 1 ساعت به عقب می‌روند (00:00 → 23:00 روز قبل)
- **نتیجه**: UTC+4:30 → UTC+3:30

## 💻 پیاده‌سازی در کد

### تابع `should_apply_dst(year, month, day)`

این تابع تعیین می‌کند که آیا برای یک تاریخ خاص باید DST اعمال شود یا خیر.

#### منطق تصمیم‌گیری:

```python
# 1. بررسی سال
if year < 1977:
    return False  # DST هنوز شروع نشده

if 2006 <= year < 2008:
    return False  # دوره لغو احمدی‌نژاد

if year >= 2022:
    if year == 2022 and month < 9:
        # تا قبل از سپتامبر 2022
        pass
    elif year == 2022 and month == 9 and day < 21:
        # تا 20 سپتامبر 2022
        pass
    else:
        return False  # لغو دائمی

# 2. بررسی ماه و روز
if month < 3 or month > 9:
    return False  # خارج از فصل DST

if month == 3 and day < 20:
    return False  # قبل از شروع DST

if month == 9 and day >= 21:
    return False  # بعد از پایان DST

return True  # DST فعال است
```

### مثال‌های کاربردی:

```python
from core import should_apply_dst, get_dst_info

# مثال 1: تابستان 2010 (DST فعال)
should_apply_dst(2010, 7, 15)  # True
# Offset: UTC+4:30

# مثال 2: زمستان 2010 (DST غیرفعال)
should_apply_dst(2010, 12, 15)  # False
# Offset: UTC+3:30

# مثال 3: سال 2007 (دوره لغو)
should_apply_dst(2007, 7, 15)  # False
# Offset: UTC+3:30

# مثال 4: بعد از لغو دائمی
should_apply_dst(2023, 7, 15)  # False
# Offset: UTC+3:30

# مثال 5: دقیقاً روز لغو
should_apply_dst(2022, 9, 20)  # True (هنوز DST)
should_apply_dst(2022, 9, 21)  # False (لغو شد)
```

## 📊 جدول کامل DST ایران

| سال | وضعیت DST | Offset تابستان | Offset زمستان | توضیحات |
|-----|-----------|----------------|---------------|---------|
| 1976 | ❌ | UTC+3:30 | UTC+3:30 | قبل از DST |
| 1977-2005 | ✅ | UTC+4:30 | UTC+3:30 | DST فعال |
| 2006-2007 | ❌ | UTC+3:30 | UTC+3:30 | لغو توسط احمدی‌نژاد |
| 2008-2022* | ✅ | UTC+4:30 | UTC+3:30 | DST بازگشت |
| 2022** | ⚠️ | UTC+4:30/3:30 | UTC+3:30 | لغو در 21 سپتامبر |
| 2023+ | ❌ | UTC+3:30 | UTC+3:30 | لغو دائمی |

\* تا 21 سپتامبر 2022  
\** قبل از 21 سپتامبر: DST فعال، بعد: غیرفعال

## 🎯 تأثیر بر محاسبات نجومی

### چرا DST مهم است؟

در محاسبات نجومی، دقت زمان بسیار حیاتی است:
- **1 دقیقه اختلاف** = تغییر در موقعیت طالع
- **1 ساعت اختلاف** = تغییر کامل در خانه‌بندی

### مثال عملی:

```
تاریخ تولد: 1390/04/15 (5 ژوئیه 2011)
ساعت تولد: 14:30 (محلی تهران)

✅ با DST صحیح:
- Offset: UTC+4:30 (چون تابستان 2011 است)
- UTC Time: 10:00
- Julian Day: 2455747.9167

❌ بدون DST (اشتباه):
- Offset: UTC+3:30
- UTC Time: 11:00
- Julian Day: 2455747.9583
- اختلاف: 1 ساعت = تغییر در موقعیت طالع!
```
