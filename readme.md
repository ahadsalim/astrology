# Nojoom Astrology App

این مخزن شامل کد اصلی اپلیکیشن نجومی Nojoom است.

## Quick Start

1. وابستگی‌ها را نصب کنید:
   - `pip install -r requirements.txt`
2. فایل محیط را بسازید:
   - `copy .env.example .env`
3. برنامه را اجرا کنید:
   - `python app.py`
